# addcn

A multi-user platform for creating and serving custom shadcn/ui registry components. Build your personal component registry and share it with `npx shadcn@latest add`.

## Features

- **Personal Registry** - Create your own component registry at `addcn.dev/r/username/component.json`
- **Organization Support** - Create organizations and collaborate with teams
- **Live Preview** - Preview components in the browser before publishing
- **shadcn CLI Compatible** - Install components with the standard shadcn CLI
- **Public & Private Components** - Control visibility with registry tokens

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Database**: Convex
- **Auth**: Better Auth (GitHub, Google OAuth)
- **Storage**: Cloudflare R2
- **Styling**: Tailwind CSS
- **UI**: shadcn/ui (Base UI primitives)
- **Icons**: Tabler Icons

## Prerequisites

- Node.js 18+
- pnpm
- Convex account
- Cloudflare account (for R2 storage)
- GitHub OAuth app
- Google OAuth app (optional)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yassinezaanouni/addcn.git
cd addcn
pnpm install
```

### 2. Set up Convex

```bash
npx convex dev
```

This will prompt you to create a new Convex project and generate your development credentials.

### 3. Set up environment variables

Create a `.env.local` file:

```bash
# Convex (auto-generated by `npx convex dev`)
CONVEX_DEPLOYMENT=dev:your-deployment
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
NEXT_PUBLIC_CONVEX_SITE_URL=https://your-deployment.convex.site

# App URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# R2 Storage (Cloudflare)
NEXT_PUBLIC_R2_PUBLIC_URL=https://your-bucket.r2.dev
```

### 4. Set up Convex environment variables

```bash
# Better Auth
npx convex env set BETTER_AUTH_SECRET "$(openssl rand -base64 32)"
npx convex env set SITE_URL "http://localhost:3000"

# GitHub OAuth
npx convex env set GITHUB_CLIENT_ID "your-github-client-id"
npx convex env set GITHUB_CLIENT_SECRET "your-github-client-secret"

# Google OAuth (optional)
npx convex env set GOOGLE_CLIENT_ID "your-google-client-id"
npx convex env set GOOGLE_CLIENT_SECRET "your-google-client-secret"

# R2 Storage
npx convex env set R2_BUCKET "your-bucket-name"
npx convex env set R2_ENDPOINT "https://your-account-id.r2.cloudflarestorage.com"
npx convex env set R2_ACCESS_KEY_ID "your-access-key"
npx convex env set R2_SECRET_ACCESS_KEY "your-secret-key"
npx convex env set R2_PUBLIC_URL "https://your-bucket.r2.dev"
```

### 5. Set up OAuth providers

#### GitHub

1. Go to [GitHub Developer Settings](https://github.com/settings/developers)
2. Create a new OAuth App
3. Set Homepage URL: `http://localhost:3000`
4. Set Callback URL: `http://localhost:3000/api/auth/callback/github`

#### Google (optional)

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Create a new project or select existing
3. Go to APIs & Services → Credentials
4. Create OAuth 2.0 Client ID
5. Add Authorized redirect URI: `http://localhost:3000/api/auth/callback/google`

### 6. Set up Cloudflare R2

1. Go to [Cloudflare Dashboard](https://dash.cloudflare.com) → R2
2. Create a new bucket
3. Go to R2 → Manage R2 API Tokens
4. Create a token with "Object Read & Write" permission
5. Copy the Access Key ID and Secret Access Key
6. For public access, enable "Public Access" on your bucket

### 7. Run the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Deployment

### Vercel + Convex

1. Push to GitHub
2. Import project in Vercel
3. Add environment variables in Vercel dashboard
4. Get production deploy key from Convex dashboard
5. Add `CONVEX_DEPLOY_KEY` to Vercel

### Environment Variables for Production

**Vercel:**

```bash
NEXT_PUBLIC_CONVEX_URL=https://your-prod.convex.cloud
NEXT_PUBLIC_CONVEX_SITE_URL=https://your-prod.convex.site
NEXT_PUBLIC_SITE_URL=https://yourdomain.com
NEXT_PUBLIC_R2_PUBLIC_URL=https://cdn.yourdomain.com
CONVEX_DEPLOY_KEY=prod:your-deploy-key
```

**Convex (production):**

```bash
npx convex env set SITE_URL "https://yourdomain.com" --prod
npx convex env set BETTER_AUTH_SECRET "new-secret" --prod
# ... other env vars with --prod flag
```
